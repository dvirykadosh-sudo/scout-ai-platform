# שלב 2 מתוך 3: האתר

זה האתר עצמו: ארבעה עמודים בעיצוב הסגול, שמתחברים לשרת משלב 1.

## מה בפנים
- **יצירת פעולה חכמה** (`/`): אשף בארבעה שלבים. פרטים, מצבים פדגוגיים, מטריצת 12 השיטות (בכל סימון מופיע "כמה זמן היא תיקח?" והזמן הכולל מתעדכן), וסקירה. בסוף מקבלים פעולה בחמישה שלבים עם כפתור ייצוא ל-Word.
- **מאגר פעולות קיים** (`/library`): חיפוש חופשי, סינון לפי גיל, שיטה ומשך, מיון ועימוד. בכל פעולה: פתיחה, ייצוא, שכפול והתאמה לגיל ולמשך. לאדמין מופיעות גם עריכה מלאה ומחיקה עם כפתור "ביטול".
- **ספריית המתודות** (`/methods`): 12 הכרטיסים, וכפתור "הוספה למחולל" שמסמן את השיטה בטופס.
- **לוח בקרה לאדמין** (`/admin`): התחברות, סטטיסטיקות, חיבורים אחרונים ויומן פעילות.
- **נגישות:** סרגל עם ניגודיות גבוהה (שחור וצהוב) והגדלת טקסט שנשמרים בין ביקורים, דילוג לתוכן, ניווט מלא במקלדת ומצבי פוקוס, והתאמה לנייד. כל העמודים עברו בדיקת נגישות אוטומטית (axe) בלי הפרות.
- **הסמל:** הנשר שבכותרת הוא סמל זמני. ראו "החלפת לוגו" למטה.

## איך מפעילים (Windows, ב-Cursor)

### 1. להכניס את הקבצים
1. קליק ימני על `stage2-website.zip` ובחר **Extract All**.
2. **Browse**, בחר `C:\Users\Dviry\Downloads\scout-ai-platform`, ואז **Extract**.
3. אמורה להופיע תיקייה בשם `frontend` ליד `backend`.

> התיקייה `scout-ai-web` שהסוכן של Cursor יצר אינה בשימוש. אפשר להשאיר אותה או למחוק אותה. אם היא רצה כרגע, עצור אותה (`Ctrl+C` בטרמינל שלה), כי גם האתר החדש משתמש בפורט 3000.

### 2. להפעיל את השרת (אם הוא לא רץ)
בטרמינל: `cd backend` ואז `npm start`. צריך לראות "השרת פועל: http://localhost:4000". אם הוא כבר רץ משלב 1, אל תיגע בו.

### 3. להפעיל את האתר
1. פתח טרמינל חדש: ליד המילה powershell בחלונית התחתונה לחץ על הסימן **+**.
2. כתוב אחת אחת:
```
cd C:\Users\Dviry\Downloads\scout-ai-platform\frontend
npm install
npm run dev
```
3. כשמופיע `Ready`, פתח בדפדפן **http://localhost:3000**.

כדי לעצור כל אחד מהשרתים לחץ `Ctrl+C` בטרמינל שלו.

### 4. מה לנסות
1. צור פעולה: מלא נושא ושם מדריך, המשך, סמן שיטות עם דקות, וצור. אחר כך לחץ "ייצוא ל-Word".
2. במאגר חפש "מכרז", סנן לפי גיל, ופתח את "פעולת שיא - קדוש".
3. ב"לוח בקרה לאדמין" היכנס עם `admin` ו-`admin123`. אחר כך חזור למאגר: יופיעו כפתורי עריכה ומחיקה.
4. לחץ "ניגודיות גבוהה" ו"הגדלת טקסט" בסרגל העליון.

### 5. לשמור (git)
```
cd ..
git add .
git commit -m "שלב 2: האתר"
```

## החלפת לוגו
1. שים את קובץ הלוגו בתיקייה `frontend\public` (למשל `logo.svg`).
2. צור קובץ `frontend\.env.local` עם השורה: `NEXT_PUBLIC_LOGO_URL=/logo.svg`
3. הפעל מחדש את `npm run dev`.

## אם משהו לא עובד
- **"אין חיבור לשרת":** השרת משלב 1 לא רץ. הפעל אותו (שלב 2 למעלה).
- **`EADDRINUSE` או פורט 3000 תפוס:** עצור את התוכנית שרצה על 3000 (למשל `scout-ai-web`).
- **הפונט:** הפונט נטען מהאינטרנט. בלי חיבור יוצג פונט רגיל של המחשב.
- **כל שגיאה אחרת:** צלם את הטרמינל והדפדפן ושלח לי.

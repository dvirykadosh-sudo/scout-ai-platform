# העלאת האתר לאינטרנט

כדי שקישור השיתוף וקוד ה-QR יעבדו לאחרים, האתר צריך להיות נגיש מהאינטרנט.
יש שתי דרכים. אני לא יכולתי להריץ אותן בשבילכם, ולכן הקבצים מוכנים אך לא נבדקו על שרת חי.

## דרך א׳: קישור זמני מהמחשב שלכם (חינם, 5 דקות)

מתאים לפעולה אחת או להדגמה. הקישור עובד רק כל עוד המחשב והחלון פתוחים, והכתובת משתנה בכל הפעלה.

1. הפעילו את האתר כרגיל (`start.bat`).
2. פעם אחת: פתחו חלון PowerShell והריצו `winget install --id Cloudflare.cloudflared`. סגרו ופתחו שוב את החלון.
3. לחצו פעמיים על `share.bat`.
4. בחלון תופיע כתובת שמסתיימת ב-`trycloudflare.com`. שלחו אותה לאחרים.
5. חשוב: פתחו את האתר **דרך הכתובת הזאת** (ולא דרך localhost) לפני שאתם לוחצים "שיתוף וקוד QR", כדי שהקישור יהיה נכון.

מגבלות לפי [התיעוד של Cloudflare](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/): אין התחייבות לזמינות, והשירות מיועד לבדיקות. בדרך הזאת אל תחשפו את האתר לתקופה ארוכה, וודאו קודם שהחלפתם את סיסמת האדמין.

## דרך ב׳: שרת קבוע (Render)

האתר נבנה כשירות אחד (אתר ושרת על אותה כתובת), עם `Dockerfile` ו-`render.yaml` מוכנים.

**חשוב על הנתונים:** המסד שומר את הפעולות, החשבונות והדירוגים בקובץ. לפי [התיעוד של Render](https://render.com/docs/disks), דיסק קבוע זמין רק בשירות בתשלום, ובלי דיסק כל הפעלה מחדש מוחקת את הקבצים. לכן לשימוש אמיתי צריך שירות בתשלום עם דיסק (המחיר העדכני באתר Render, בדרך כלל כמה דולרים בחודש). בנוסף, האתר מגבה את עצמו אוטומטית פעם ביום, ואפשר להוריד גיבוי מלוח הבקרה.

### שלבים

1. **GitHub:** פתחו חשבון חינם ב-github.com וצרו מאגר חדש **פרטי** בשם `maoz-activity-generator`.
2. **העלאת הקוד:** בתיקיית הפרויקט פתחו טרמינל והריצו, שורה אחר שורה (החליפו את הכתובת בכתובת של המאגר שלכם):
   ```
   git init
   git add .
   git commit -m "first version"
   git branch -M main
   git remote add origin https://github.com/YOUR-NAME/maoz-activity-generator.git
   git push -u origin main
   ```
3. **Render:** פתחו חשבון ב-render.com, ובחרו New > Blueprint, חברו את GitHub ובחרו את המאגר. Render יקרא את `render.yaml`.
4. **משתנים שיבקשו מכם:**
   - `ADMIN_PASSWORD`: סיסמה חזקה לאדמין. **חובה.** בלעדיה השרת לא עולה בפרסום.
   - `SIGNUP_CODE`: קוד שתיתנו למדריכים כדי שיוכלו להירשם. אם תשאירו ריק, ההרשמה סגורה ואתם פותחים חשבונות ידנית בלוח הבקרה.
   - `ANTHROPIC_API_KEY`: לא חובה (ראו README).
5. חכו כמה דקות לבנייה. Render ייתן כתובת בסגנון `https://משהו.onrender.com`.
6. היכנסו ללוח הבקרה עם `admin` והסיסמה שבחרתם, ובדקו שהכול עובד.
7. כדי להשתמש בכתובת משלכם (למשל `maoz.co.il`), מוסיפים Custom Domain בהגדרות השירות ב-Render.

### תחזוקה

- **עדכון גרסה:** מחליפים את הקבצים, ואז `git add .`, `git commit -m "update"`, `git push`. Render בונה מחדש לבד.
- **גיבוי:** בלוח הבקרה, תחת "גיבויים", לחצו "הורדה" פעם בשבוע ושמרו את הקובץ במקום אחר (כונן, מייל).
- **שחזור:** מחליפים את הקובץ `scout.db` בדיסק בקובץ הגיבוי ומפעילים מחדש. אם צריך, ביקשו ממני הוראות.

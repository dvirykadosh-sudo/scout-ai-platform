# שלב 1 מתוך 3: המנוע של מחולל הפעולות

זה "המוח" של האתר. אין בו עדיין עיצוב (זה שלב 2), אבל הוא כבר עושה את כל העבודה האמיתית.

## מה נבנה בשלב הזה
- **מסד נתונים אמיתי** (SQLite): הפעולות נשמרות גם אחרי שסוגרים את השרת.
- **חמש הפעולות המוכנות** (קדוש, אלימות, בריונות, תחבורה בשבת, ממונהג למנהיג) נטענות אוטומטית, עם חמישה שלבים וזמנים מדויקים.
- **מחולל פעולות:** מקבל נושא, ערך, גיל ושיטות עם דקות לכל שיטה, ומחזיר פעולה בחמישה שלבים. הזמן הכולל תמיד שווה בדיוק לסכום הדקות שהוזנו, והסיכום תמיד מקשר למידה ד' ומידה ח'. בלי מפתח AI הוא משתמש במחולל מובנה. עם מפתח (`ANTHROPIC_API_KEY`) הוא משתמש ב-Claude, ואם Claude נכשל הוא חוזר למחולל המובנה.
- **ייצוא Word בעברית (RTL):** כותרת בפורמט `[מדריך] . [פעולה] + [שבט] ו-[גדוד]`, טבלת שלבים, מספרי עמוד.
- **חיפוש וסינון** לפי טקסט, גיל, שיטה, ערך ומשך.
- **אדמין מאובטח:** סיסמה מוצפנת, נעילה אחרי 5 ניסיונות כושלים, עריכה, מחיקה עם אפשרות שחזור, חיבורים פעילים, יומן פעולות וסטטיסטיקות.
- **מייל לאדמין** על כל פעולה חדשה (בלי הגדרות מייל הוא רק נרשם בלוג).
- **20 בדיקות אוטומטיות.**

## איך מפעילים (Windows, ב-Cursor)

### 1. להכניס את הקבצים
1. לחץ קליק ימני על הקובץ `stage1-engine.zip` שהורדת, ובחר **Extract All**.
2. לחץ **Browse** ובחר את התיקייה `C:\Users\Dviry\Downloads\scout-ai-platform`, ואז **Extract**.
3. ב-Cursor, בעץ הקבצים משמאל, אמורה להופיע התיקייה `backend`. אם היא לא מופיעה, לחץ על אייקון הרענון בראש העץ.

### 2. להתקין (פעם אחת)
1. ב-Cursor לחץ `Ctrl+J` כדי לפתוח את הטרמינל.
2. כתוב את הפקודות האלה, אחת אחת, וסיים כל אחת ב-Enter:
```
cd backend
npm install
```
3. חכה כדקה עד שחוזרת השורה המהבהבת. אם מופיעה שגיאה אדומה שאומרת שהרצת סקריפטים חסומה, כתוב `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, אשר עם `Y`, ונסה שוב.

### 3. לבדוק שהכול תקין
```
npm test
```
בסוף צריך להופיע `# pass 20` ו-`# fail 0`. אזהרה על SQLite ניסיוני היא תקינה.

### 4. להפעיל
```
npm start
```
אתה אמור לראות:
```
השרת פועל: http://localhost:4000
נטענו 5 פעולות מוכנות למאגר
```
פתח בדפדפן **http://localhost:4000**. יופיע דף בדיקה עם קישורים: לחץ על "רשימת הפעולות" ועל "הורדת Word של פעולה 1".

כדי לעצור את השרת לחץ `Ctrl+C` בטרמינל.

### 5. לשמור (git)
```
cd ..
git add .
git commit -m "שלב 1: המנוע"
```

## הגדרות (לא חובה)
כדי לשנות הגדרות, העתק את `.env.example` לשם `.env` (בתוך התיקייה `backend`): `copy .env.example .env`, ופתח אותו לעריכה. אפשר להגדיר מפתח AI, מייל לאדמין, ופורט.

## כניסת אדמין
שם משתמש `admin`, סיסמה `admin123`. זה מתאים רק לפיתוח. לפני שהאתר עולה לאינטרנט חובה להחליף סיסמה.

## אם משהו לא עובד
- **`EADDRINUSE`:** הפורט תפוס. הוסף ל-`.env` את השורה `PORT=4001`.
- **`npm` לא מזוהה:** סגור את Cursor ופתח אותו מחדש.
- **כל שגיאה אחרת:** צלם את הטרמינל ושלח לי.

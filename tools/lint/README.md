# בדיקת קוד (ESLint) לשרת

ההתקנה נפרדת מהאתר, כדי שבנייה ב-Render לא תתקין את הכלים האלה.

```
npm run lint:setup   # פעם אחת: מתקין את ESLint בתיקייה הזו
npm run lint         # בודק את backend/src ו-backend/test
```

שגיאה (error) אומרת שיש באג אמיתי: משתנה שלא הוגדר, קוד שלא מגיעים אליו או מפתח כפול. אזהרות (משתנה שלא בשימוש) אינן עוצרות כלום.
